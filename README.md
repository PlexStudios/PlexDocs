# PlexDocs

Central documentation for the Plex Studios plugin ecosystem.

## Projects

- [PlexVariables](docs/plexvariables/README.md) custom PlaceholderAPI variables with conditions, expressions, nesting, and persistent storage
- [PlexKillstreaks](docs/plexkillstreaks/README.md) configurable killstreak tracking for Paper servers
- PlexAware — documentation will be added when the project is ready for public release

## What Belongs Here

PlexDocs is intended for:

- installation guides
- configuration references
- commands and permissions
- placeholder documentation
- troubleshooting
- compatibility notes
- cross-project guides
- public documentation for paid projects whose source code remains private

Project source code remains in each project's own repository.

## Documentation Layers

A project README provides the fast overview.

Complex projects can use a GitHub Wiki for detailed project-specific manuals.

PlexDocs provides the central public documentation layer across the Plex Studios ecosystem.
