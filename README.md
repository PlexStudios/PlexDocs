# PlexDocs

Central documentation for the Plex Studios plugin ecosystem.

## Projects

- [PlexKillstreaks](https://github.com/PlexStudios/PlexKillstreaks) — configurable killstreak tracking for Paper servers
- PlexVariables — custom PlaceholderAPI variable engine
- PlexAware — lightweight contextual survival QoL assistant

## What Belongs Here

PlexDocs is intended for:

- Installation guides
- Configuration references
- Commands and permissions
- Placeholder documentation
- Troubleshooting
- Compatibility notes
- Documentation for paid projects whose source code remains private

Project source code remains in each project's own repository.
