# PlexKillstreaks

PlexKillstreaks is a lightweight and configurable killstreak plugin for modern Paper servers.

## Requirements

- Paper 1.21+
- Java 21
- PlaceholderAPI is optional

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| `/streak` | View your current and highest streak | `plexkillstreaks.streak` |
| `/streaks` | Alias for `/streak` | `plexkillstreaks.streak` |
| `/streakreload` | Reload configuration | `plexkillstreaks.reload` |

## Placeholders

```text
%plexkillstreaks_current%
%plexkillstreaks_highest%
%plexkillstreaks_next_milestone%
%plexkillstreaks_progress%
%plexkillstreaks_is_active%
%plexkillstreaks_loaded%
```

More detailed configuration documentation can be added as the project evolves.
