# Plex Studios Documentation

Welcome to the central documentation source for Plex Studios.

## Available Projects

### [PlexKillstreaks](plexkillstreaks/README.md)

Lightweight killstreak tracking with configurable milestones, SQLite persistence, and optional PlaceholderAPI support.

Repository: https://github.com/PlexStudios/PlexKillstreaks

### [PlexVariables](plexvariables/README.md)

Custom PlaceholderAPI variables using static values, conditions, expressions, nested variables, and persistent storage.

Repository: https://github.com/PlexStudios/PlexVariables

### [PlexDeathCoords](plexdeathcoords/README.md)

Recent death-location tracking with saved coordinates, configurable chat messages, and optional compass targeting.

Repository: https://github.com/PlexStudios/PlexDeathCoords

## Experimental projects

### PlexAware

An experimental survival quality-of-life assistant built around contextual awareness. Public documentation will be expanded if the project is released.
